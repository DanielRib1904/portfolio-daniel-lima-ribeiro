# 🎬 AT3 Calculadora IMC

## 📝 Descrição do Projeto

Este projeto consiste em uma calculadora interativa de Índice de Massa Corporal (IMC) desenvolvida para auxiliar usuários a avaliarem sua faixa de peso de forma simples e intuitiva. O objetivo principal é fornecer um diagnóstico rápido baseado na relação entre peso e altura, classificando o resultado de acordo com as diretrizes da Tabela de Resultados para Adultos da OMS/ABESO.

Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End Para Web (2026.2)**, a aplicação coleta as entradas de peso (em kg) e altura (em metros), executa o cálculo aritmético $IMC = \frac{\text{Peso}}{\text{Altura}^2}$ via JavaScript e atualiza dinamicamente o DOM para exibir a pontuação final acompanhada de sua respectiva classificação (desde "Baixo peso" até "Obesidade grau III").

## 🚀 Tecnologias Utilizadas

* **Linguagem:** HTML5, CSS e JavaScript (Manipulação de DOM e validações)
* **Bibliotecas:** Bootstrap
* **Ferramentas:** VSCode
* **Modelo de IA:** Gemini

## 📊 Resultados e Aprendizados

O projeto entregou uma interface funcional e responsiva, garantindo precisão no processamento das informações inseridas pelo usuário.

* **Precisão no Cálculo:** Implementação da fórmula exata de IMC com tratamento de casas decimais (`toFixed(2)`).
* **Manipulação Dinâmica do DOM:** Aprendi a capturar valores de inputs em tempo real e injetar os resultados diretamente em tags HTML com feedback visual conforme a classificação.
* **Validação de Dados:** Implementação de verificações para garantir que os valores de peso e altura inseridos sejam válidos antes de realizar a operação matemática.

## 🧠 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial (Gemini) estritamente como ferramenta de suporte tecnológico para a estruturação inicial do código HTML e suporte na lógica de validação do JavaScript. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
